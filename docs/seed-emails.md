# Seed emails for the "Leash Demo" label

Kyle sends all three himself from a second account to his Alumni Gmail, then applies the Gmail label "Leash Demo" to each. The example.com names in the bodies are fictional; the real sender is Kyle's second address. Send them before the demo so Mail has synced the label (open Mail and check the "Leash Demo" mailbox under Alumni shows 3 messages).

Tip: put the fictional sender's name in the second account's display name for emails 1 and 2 (for example "Alex Rivera"), so the agent's summary reads naturally. If you can't change it quickly, the signature carries the name.
